How does Playwright auto-wait for buttons?
Playwright checks actionability: element is visible, stable, receives events, and is enabled before clicking.
What is the difference between page.wait_for_timeout and expect auto-retrying?
Hard sleep (`wait_for_timeout`) causes flaky or slow tests. Playwright's `expect` assertions automatically poll until the condition is met or timeout expires.

Recommended conftest.py Setup 

import pytest
from playwright.sync_api import sync_playwright

@pytest.fixture(scope="session")
def browser_context():
    with sync_playwright() as p:
        browser = p.chromium.launch(headless=True)
        context = browser.new_context(
            viewport={"width": 1600, "height": 900}
        )
        yield context
        context.close()
        browser.close()

@pytest.fixture
def page(browser_context):
    page = browser_context.new_page()
    page.goto("http://localhost:8000")
    yield page
    page.close()

Key Automation Principles in this Playground

Locators First

Always prefer user-facing role locators (get_by_role) or accessible labels over fragile CSS classes.

Auto-Waiting

Avoid arbitrary sleeps like time.sleep(). Playwright automatically awaits visibility and stability.

Parametrization

Leverage @pytest.mark.parametrize to execute multiple permutations without code duplication.
